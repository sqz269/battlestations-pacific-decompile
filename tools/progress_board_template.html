Reconstructed means the address has a function record in the reconstruction ledger or a column-0 C++ definition named after it under src/, whichever came first in git history. It says nothing about ABI compatibility or game validation; those are separate levels.
Reviewed name means a record in the names ledger. Names are hypotheses, not recovered symbols.
Excluded by tag is CRT, STL instantiations, stock Lua and zlib, exception funclets and compiler-generated bodies from the inventory tag ledger; tags do not approve skipping a function.
The target of 13,987 is the inventory's point estimate of hand-reconstruction work; the remaining pool is what is left after tags and reconstructed functions are removed. Harness attribution follows commit trailers: a Claude trailer means Claude, everything else is Codex.

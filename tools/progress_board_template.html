Click a column to sort. Use the legend above the map to hide categories here as well.

Reconstructed means the address has a function record in the reconstruction ledger or a column-0 C++ definition named after it under src/, whichever came first in git history. It says nothing about ABI compatibility or game validation; those are separate levels.
Reviewed name means a record in the names ledger, dated by the commit that added it. Names are hypotheses, not recovered symbols. Name from analysis is a Ghidra name that is not FUN_ and has no ledger record: library identification, RTTI, or an early manual rename; it is shown from the start because its date is not in the repository.
Excluded by tag is CRT, STL instantiations, stock Lua and zlib, exception funclets and compiler-generated bodies from the inventory tag ledger; tags do not approve skipping a function. Exception funclets and thunks are left out of the per-function view.
The target of 13,987 is the inventory's point estimate of hand-reconstruction work; the remaining pool is what is left after tags and reconstructed functions are removed. Harness attribution follows commit trailers: a Claude trailer means Claude, everything else is Codex.

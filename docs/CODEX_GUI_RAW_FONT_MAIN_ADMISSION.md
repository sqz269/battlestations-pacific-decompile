# Fixed Font and MainSection composition

The appended `geometry_main_section_font` operation binds one immutable tuple of
the existing Geometry context, Main helper and mutable typed Font helper. The
pointer itself is fixed; Font admission keeps its existing typed mutation API.
Old None/GeometryOnly/Main-only constructors preserve their kind/identities and
leave the Font peer absent. This declaration alone grants no lifetime permission.
Existing guards reject the new kind until the coupled implementation is reviewed.

Native ABB630 Font selection precedes its conditional ABAED0/ABA8D0 submission;
ABA8D0 ensures Main then reads the existing Font. New owner work must select Font
before Main, with no unconditional Shader invocation. The first combined domain
joins those real fragments with empty content; raw property/localisation/content,
AB8400/nonempty buffers, glyph/layout/parenting and Page/P4 remain separate work.

Main owns the created-normal sole Section/Material/Model custody slice. Font owns
108/1C8/1CC/1EC, actual private publications and exact shader credit. Shared gates
authenticate both exact peers while alive. Neither helper may traverse a sibling
in post/retention/destruction; old domains retain their original field policies.
Prepared reservations must permit the genuine earlier Font operation without
granting scalar permission before Main's created-normal seal.

The immutable API passes independent actual-diff review and the Win32 build/both
existing checks (13.00s). Coupled implementation/review remain pending. No native credit, ABI,
runtime, renderer or production activation is claimed; all private switches stay OFF.

# CC13 left8b: segment 8 large leftovers

Packet cc13-left8b took the 17 large segment-8 functions (00491170..004BA200)
that cc13-left8 (docs/CC13_LEFT8.md) did not reach. Code:
`src/cc13_left8b_seg8.cpp`, `include/bsp/cc13_left8b_seg8.hpp`. The host
interface `Left8bHost` extends cc13-left8's `Left8Host` with the calls these
bodies make that had no hook; every hook is invoked where the image calls the
named routine. Objects keep their Win32 byte layout through the `at<T>()`
helpers. Status: reconstructed and build-tested; not ABI-compatible, not
game-validated. Only 0049A760 draws from the shared RNG 00BD2F10 (and 00439950, which
draws a direction from it); the other picks are deterministic hashes.

The x87 reg-reg forms were read from the bytes (`tools/x87_dc_form_scan.py`),
not the listing. Where the image stores an intermediate to a float, the C++
rounds there; sums and products are formed in double rather than 80-bit
extended before each store (last-bit differences only).

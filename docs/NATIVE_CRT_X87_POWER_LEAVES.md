# Native CRT x87 power leaves

This packet reconstructs the complete **00C08390..00C083A5 [21 bytes]** x87 exponent sequence and **00BFED32..00BFED5A [40 bytes]** exponent-classification sequence. Both bodies use naked MSVC Win32 assembly. The first is byte-identical to the original; the second differs only in the explicitly declared address operand of its six-byte FMUL. No host exp2, pow, integer cast, or arithmetic branch replaces the original instructions.

The names `exp2_native_crt_x87_00c08390` and `classify_native_crt_power_exponent_00bfed32` are descriptive hypotheses. ## Assembly-only source interfaces

Both declarations in [native_crt_x87_power_leaves.hpp](../include/bsp/native_crt_x87_power_leaves.hpp) are **for assembly callers only**, with raw ST0 input. A void C++ declaration neither models the floating-point/register results nor makes ordinary C++ invocation safe. The caller must manage the x87 stack, capture required outputs before clobbering them, and accept the current x87 control, precision, rounding, status and exception behavior. Neither entry saves or resets the FP environment, masks exceptions, translates faults, or promises normal return after a fault. These are new source interfaces, not installed binary replacements.

`void __cdecl exp2_native_crt_x87_00c08390()` requires ST0 plus two free x87 stack slots. The original sequence duplicates ST0, FRNDINTs the copy, computes the signed fractional difference, executes F2XM1, adds one, FSCALEs by the rounded integer and discards that intermediate. On normal return one result replaces the original ST0; older stack entries survive. General registers and integer EFLAGS are untouched; there are no stack arguments and the exit is RET. No numerical claim extends beyond the instruction sequence and its current processor environment.

`void __fastcall classify_native_crt_power_exponent_00bfed32(void* unused_ecx, const void* actual_half_00e15850)` requires ST0 plus one free x87 stack slot. EDX borrows a live eight-byte half cell, expected to bind the original immutable 0.5 literal (`00 00 00 00 00 00 E0 3F`). The pointer is used only if the first comparison accepts; no entry-time read, value snapshot, copied constant or generic callback is added. ECX has no algorithm input meaning, but only CL is written and the upper 24 bits survive. Waiting FSTSW AX writes only AX, leaving the upper 16 EAX bits intact. EDX and nonvolatile registers survive. Both exits use RET and there are no stack arguments.

The classification entry duplicates and rounds ST0, compares/pops the duplicate, writes CL=0, then performs **FWAIT; FNSTSW AX; SAHF**. If the first ZF equality test rejects, it pops the original ST0 and returns CL=0. Otherwise it multiplies the still-live ST0 by the borrowed half cell, increments CL, duplicates/rounds that product and FCOMPPs both values. A second **FWAIT; FNSTSW AX; SAHF** supplies the next ZF test: rejection returns CL=1, acceptance increments to CL=2. Every normal path consumes the original ST0 and leaves older x87 entries beneath it.

Those are instruction-level CL outcomes. They yield integer parity when rounding and precision leave the half-product classification exact. Reduced x87 precision can round a large odd integer's half to an integer, so finite input alone does not guarantee the usual odd/even result. Unordered comparisons and masked/unmasked exceptions also retain original behavior; CL is not a validated C++ enum. Integer flags come from the final executed SAHF or INC CL, including bits those instructions preserve. The original waiting forms can deliver pending unmasked x87 exceptions before reading status; they are not replaced with nonwaiting stores.

## One explicit operand adaptation

At original BFED40 (function offset 14), bytes `DC 0D 50 58 E1 00` encode `FMUL qword ptr [00E15850]`. The new body uses `DC 8A 00 00 00 00`, encoding the single instruction `FMUL qword ptr [EDX+disp32(0)]`. Six `_emit` lines are one decoded instruction, not added operations. Explicit disp32 preserves its length, all later addresses relative to the entry, both branch displacements, both returns and both waiting FSTSW byte triples (`9B DF E0` at offsets 8 and 28).

The borrowed pointer changes the original ABI and data-address binding; it is not an original-address/drop-in claim. Under the binding contract, the current FMUL reads the expected original half cell at its native point in the instruction order. Wrong, unreadable or mutable cell contents are not silently corrected. The original E15850 eight bytes are freshly pinned; no claim is made that an arbitrary supplied pointer has that provenance.

The proof independently decodes all 40 compiled bytes and checks each instruction address, size, mnemonic and operand. Only the memory addressing of this one FMUL is admitted as different. Its compiled operand must be exactly an eight-byte read based on EDX with zero displacement and no index. All other bytes, including control transfers, must match. C08390's entire 21-byte body must match without any normalization. Neither function has a call or COFF relocation; no other provider, allocator, owner, or error-dispatch context is introduced.

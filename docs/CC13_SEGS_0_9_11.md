# Segments 0, 9 and 11 (cc13-segA)

Code: `src/segs_0_9_11_cc13.cpp`, `include/bsp/segs_0_9_11_cc13.hpp`. Every name is a hypothesis.
Objects are raw image storage; each engine routine or virtual slot the image calls is a named
`Segs0911Host` method invoked at the same point with the same arguments. Status: reconstructed and
build-tested; nothing here is ABI-compatible or game-validated.

## Scope

- Segment 0, packet range 00410630..00412FA0.
- Segment 9, packet range 004BC410..004D0860.
- Segment 11 (004E8BF0..004F9D30) was not touched: agent/argon-v2 holds the lease
  `argon-v2-seg11` over 004E7E40..004F9D30 (files `src/mission_thunk_seg11_argon.cpp` and
  `docs/ARGON_SEG11_MISSION_THUNK.md`).

## Corrections to earlier notes

- 00410D80/00410E00: 00CE37B0 is "freq" and 00CE37A8 is "time". The pair is {freq +0, time +4};
  the earlier ledger text had them the other way round.
- 00411F80: the third and fourth floats are 1.5 then 150.0 (00CE380C, 00CE3808), not 150, 1.5.
- 004C6B20: 00425D10 is `__cdecl(void)`; the pushed 0 is the argument of 00530630, which stores it
  at byte +3Ch of the menu command screen. The earlier note read it as "00425D10(0)".
- 00411350 (`BotStateRegistry_IndexOf`) returns -1 for every input, so 00411450 always saves
  `stateIndex = -1`, and a load through 00411170 of that value fails the range test (00BF6713).

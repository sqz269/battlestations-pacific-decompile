Let `U(x)` mean modulo `2^32`, with entry `ESP=s0`, `EBP=b0`, `ESI=i0`. The initial PUSH of EBP precedes the stack-word read `a0=SS:[s0+4]`; PUSH of ESI then precedes the slot read. LEA produces `S=U(8*a0+0x00E16478)` without a memory read or segment-base addition. This is an 8-aligned offset with a selector alias period of `2^29`; neither valid selector range nor table extent is known. The report models ordered reads and writes so aliases are not silently excluded.

There are three distinct ways to reach B5. Initial slot nonzero reaches it without an earlier CALL, with `ESI=S` and `ESP=U(s0-8)`. After initial zero and a first-call continuation, TEST uses the new, unconstrained EAX; nonzero reaches B5 after one POP, with unconstrained ESI and the continuation ESP plus four. If that EAX is zero, the second call is reached; a designated continuation and another completed POP reach B5 with another unconstrained state. The name `__amsg_exit` does not remove this conditional path.

B5 reads the current slot value before pushing it. It then reads the indirect target after that argument PUSH and before the CALL's return-address write. The pushed argument can alias the pointer location. Even the initial nonzero path reads the slot twice, so it does not establish a stable nonzero argument without a memory/environment contract. DS slot/pointer accesses, SS frame accesses, code and mapped backing memory can alias.

At B6 let the opaque continuation state have `ESP=s3`, memory `M3` and stack segment `SS3`. The two pops and RET consume `SS3:[s3]`, `SS3:[s3+4]`, `SS3:[s3+8]`, leaving `ESP=U(s3+12)`. Local restoration requires those words to equal the incoming ESI, EBP and entry stack return word, with a suitable return code context. Under the usual same-frame mapping, this requires `s3=U(s0-8)` and intact saved words. If B5 began at `s0-8`, its CALL entered at `s0-16`; the continuation must therefore account for both the pushed return and argument words. None of that cleanup behavior is established by the bytes or external name.

EBP register preservation by the callees is not required by these visible local operations: after the initial stack-word load, the next EBP use is the restoring POP. Likewise the final callee need not preserve ESI/EBP registers for those pops to restore them; it must meet the stack/memory/context conditions. Preserving ESI across earlier calls would be a sufficient same-slot condition, but an equivalent segment/offset/backing-memory association could also suffice. The report separates exact value conditions from these stronger conventional frame assumptions.

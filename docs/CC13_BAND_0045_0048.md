# CC13 band 00450000-0048FFFF

cc13-sweep45, 2026-10-12. A naming, tagging and leaf-reconstruction sweep of the non-gameplay
code in 00450000-0048FFFF (partition segments 4 to 7). cc13-sweep40 covers 00400000-0044FFFF.
Nothing here was run in the game: names and tags are applied in Ghidra, the C++ is build-tested only.

## Method

1. Template copies: the cc13-stl1 shape pipeline (`tools/template_shapes/st1_*`) copied into the
   tree's `local/s45ts/` with the target filter widened to `00450000 <= address < 00490000` (and the
   reviewed decision examples kept as targets so their groups resolve after they were renamed). Its
   reviewed decisions, auto twins, rules and family regexes were reused unchanged; the rows were
   filtered to this band before writing and the tag `source` points at this document.
2. Body twins: a second pass over the same shape signatures matched remaining raw bodies against
   *named* functions (`fine` signature = identical instruction stream with call targets and
   constants normalised). Only identical-body matches whose semantics are generic (string
   storage, pair copy, tree node construct, pointer-array reserve/push, range copy) were named,
   with an `_<ADDR>` suffix. The `mov [global],0 / ret` twins were named only after reading which
   singleton getter reads each global.
3. Anchors: string literals (`Dialogues`, `dialogState`, `cloudclass`, `System error`, SoldierGlobals.lua
   keys, soldier-type Lua keys), singleton globals, class ids at +C4h and vtable slots, and
   `docs/CC13_SCENE_BROWSER.md` (the 37h entity family and the per-class +A0h init).

## Notable findings

- `00485520` is the SoldierGlobals singleton (`00F87544`); its first use runs `0084CB70`, which loads
  `Scripts\datatables\SoldierGlobals.lua` (ShadowClipDistance +4, FireEfxClipDistance +8,
  ClipDistance +0Ch, MaxParatrooperGradient +10h, ParachuteOpenAltitudeMin/Max +14h/+18h). The
  37h entity base constructor `00489F30` draws its phase from `BSP_Random_UniformFloatRange`
  scaled by ClipDistance, so constructing any anim/bullet/buoy/cloud/vehicle-visual entity
  consumes the shared generator (RNG RULE: a host that wires this must keep it on stream 0 only
  where the image does).
- `00451E50` is the network handler for StartDialog: it runs a Lua buffer from the session
  message and starts `Dialogues[name]` through `00451A90`, the same routine
  `BSP_LuaBinding_StartDialog` uses. `00452130` restores the dialog state from a save
  ("dialogState", "actDialogID", "dialogs").
- `0046F940..004702E0` (doc'd as statically unreferenced in CC13_SCENE_BROWSER) is a small
  vector library: point-line distance, closest point, ray-plane intersection, axis projection and
  rejection. 0046F440 and 0046FF70 do have callers in segment 46 (007AEEC0, 007AE7B0).

# Raw Icon state repeated construction: normal support

This ignored proposal implements the normal counted-fill schedule at AB5400
using the already reconstructed raw AB3A70/context. It is not the whole Native
function: the 13 catch-landing rows AB545B..AB5477 remain held. The complete
physical body is 143 bytes/55 rows; Ghidra counts 42 outside that landing path.

Native ECX destination and full unsigned EDX count become explicit ordinary
Source parameters. Four volatile incoming DWORD homes and five ordinary retained
frame objects preserve the reached Source homes. There is no home initializer,
value-initialized frame, FS/savedESP fiction, owner or metadata authority.

The initial state -1/progress/begin/full-state0 stores precede the unsigned loop.
Each iteration writes slot/placement and low-byte state1, then null skips the
object birth and source read. A reached nonnull slot receives an individual
no-field-write default placement birth of the existing real 40h state, followed
by a CURRENT read of the SAME first source home and direct AB3A70. Source does
not advance. Count decrement, DWORD-wrap cursor+40h, low-byte state0 and progress
store follow each normal return/skip. The other three homes remain preimages.
There is no T[n] requirement, count cap, new filter or a progress ownership proof.

The inherited copy contract is frozen verbatim in the report: actual CPP19-22
and126-152 plus H105-115 (boundary116), with exact byte hashes. It requires distinct valid
records and genuine pool/string/canonical texture+04/registry domains. Its old
bool-preserve resize and std::memcpy do not establish exact BF0, mutable preserve
HOME, overlap/private-alias, fault or Original contracts. This proposal does not
silently strengthen them or introduce a replacement copy/helper/virtual bridge.

An escaping Source call is UNKNOWN. No catch destroys a completed prefix or
replays a Native action. The reviewed caller must retain real homes, frame,
context, partial/current/completed records, payload/backing and custody through
the escape and provide explicit later disposition. Source control/frame backing
is separate from provider-write extents. Distinct reentrant calls require distinct
retained frame/home backing; genuine callbacks may change the late source home.
Normal completion, passive state/progress and an entered slot mint no EH/Origin,
ownership or retirement permission. No new noexcept/cleanup/terminal policy exists.

Native handler CB7CA1, FuncInfo DEE954, maps DEE93C/DEE928 and action CB7C90 are
operand evidence only. The Native catch destroys a completed prefix via AB3280
and rethrows through BF6885; neither path is reconstructed or authorized here.

and exact provider/subobject lifetimes remain actual caller proofs.

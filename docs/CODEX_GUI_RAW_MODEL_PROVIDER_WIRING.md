## Point-light identity that must be chosen explicitly

`NativeNodeDestructionRuntime` owns `point_lights` BY VALUE
(`native_node_destruction.hpp43`). StartupSceneDomain separately owns another
instance (`game_native_renderer_gui_scene.inc210/251`). e75 requires the raw
Model tree point-light service to equal Text base/glyph `nodes.point_lights`.

Therefore construct the private Model tree with
`renderer.camera_environment().nodes.point_lights`, alongside the shared actual
owners/import cell, e769 dispatcher and shared recursive frame provider. Its
private raw node context borrows that tree, private raw scene context, SAME VFS
raw strings and the shared genuine world provider. This preserves the existing
base-runtime identity without modifying A1 or inventing a point-light service.
The DEFAULT empty descriptor admission remains explicit; foreign light/backing
bindings cannot be adopted or inferred from an empty count.

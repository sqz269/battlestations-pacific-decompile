No additional Element completion cell is needed under the actual supported Source proof, independently challenged by `gui_group_factory_inputs_review`:

1. Element is private and loader-zero; only Text/new Group can enter its cold adapter. Layer already requires completed Text. A hot Element has prior normal Text/Group completion, or the new cold cross-entry check rejects the prior entered failure. There is no unexplained external writer.
2. Both calls use the same concrete final `CounterHost`/`TypeIdCounterLifetime`, never an arbitrary `GuiTypeCounterHost`. A normally completed cold Element has completed that lifetime's getter and ID update with a valid nonnull published object.
3. The publication/object and actual counter/root domain stay alive, non-retiring and unchanged through subsequent role initialization and consumers. External serialization excludes clearing/replacing/deleting the counter, reentry and races. The actual VFS/manager graph is retained through shared drain.
4. After Element returns, Group has only its bounded DWORD loads/stores before the next getter; Text has only primitive parent copies. The concrete getter's nonnull fast arm (`light_type_bootstrap.cpp:23-24`) is load/branch/return, with no manager, allocation, registration, validation or callback that can throw. The remaining uint32 operations and completion assignment do not throw. Consequently a supported ordinary C++ role failure after completed Element is unreachable; the cold cross-entry rejection does not falsely poison a completed Element.
5. This is conditional Source reasoning. Fault/SEH/nonlocal escape, invalid storage, foreign providers, concurrent publication retirement and Native private epochs are not covered. A future throwing warm getter, added post-parent call/logging/validation, newly allowed counter reset or relaxed lifetime/serialization invalidates the proof; then track actual Element completion instead of broadening a failed-role veto. Completed getters/own-role warm entries must remain usable under their existing contracts.

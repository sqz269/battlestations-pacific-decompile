# Prepared particle record: primary acceptance

The stable noncopyable record borrows the genuine prepared Native model owner,
its raw slot and live services. It owns inline optional reference storage and
the existing generated-model and canonical-registry admissions. Preparation
validates extent, identity and shared scene/registry authority before reserving
host metadata; it does not read raw+04 or allocate a Native model.

Publication occurs only after the Native base is live. Admitted-reference
construction precedes consuming registry publication, with no intervening
external callback, Native call or yield. The noexcept hook treats invariant,
construction or mutex failures as terminal. This is not a universal recoverable
failure or heap-free guarantee. Existing failed construction retirement waits
for owner dead; it does not invent successful-model destruction, count reversal
or ownership for the weak particle-manager array.

The disposal callback unbinds the saved opaque identity and marks the record
retired. It does not inspect Native fields or destroy the reference on its own
callback stack. Explicit host disposal requires later proven quiescence of all
construction, hooks, callbacks, terminal and resolver borrows. Native terminal
slot return and serialized metadata removal precede host destruction; services,
registry and borrowed owner lifetime remain caller obligations.

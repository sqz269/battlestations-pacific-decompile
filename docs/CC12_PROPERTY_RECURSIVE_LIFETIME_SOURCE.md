This packet implements the **six complete ordinary lifetime bodies together**
in the existing registered `src/native_scene_property_bag_storage.cpp`.
`include/bsp/native_scene_property_recursive_lifetime.hpp` exposes the borrowed
canonical context and complete C++ interfaces. Genuine nonnull type-6 children
recursively reach the whole bag scalar, bag destructor and owning map clear;
mapped records reach the whole record scalar, phase publication and per-type

Names are descriptive hypotheses, not recovered symbols.

## Operations and bindings

Actual CE89D4 records bind directly to the complete named Source record
scalar. Actual D16504 children bind directly to the complete named Source bag
scalar. The genuine phase DWORDs remain Original data; Source never calls an
Original numeric address or dereferences them as Source vtables. A numeric
phase match alone does not establish allocation provenance. No synthetic
record, bag, owner, profile array, opaque destructor or arbitrary allocator
callback is introduced.

The Source-only context borrows the actual private-constructor canonical
`GameNativeStringProcess` and `GameNativePhysicalPoolProcess`. Its complete
32-byte emitted constructor takes the former's real raw string context and
calls the latter's guarded E175B0 pool getter once, before lifetime work.
It stores two borrowed pointers; it constructs no native owner or pool.
Recursive calls reuse that binding without extra process-getter calls.

Map clear visits all 64 heads at actual map `+8+4*i`, regardless of count.
Its emitted body loads mapped record at `+8` and saves next at `+C` before
the actual record-scalar `CALL +6A`. A nonnull mapped value receives flags
`1`; node `+8` is zeroed at `+7F` only after the scalar returns. The actual
node's first eight bytes are passed as the real key header at `CALL +85`.
`CALL +8E` then returns that exact allocated slot to the same E175B0 pool.
The loop advances using saved next, without reading a returned slot. Each
head is zeroed after its chain at `+AC`; only after the 64-head loop does
`+CD` zero count. Allocator node `+10`, key header and unrelated fields remain
untouched by the caller.

The complete concrete raw-header provider is 51 bytes/26 instructions and
directly calls the real string-pool getter and return provider. Null key data
skips length and provider access. Nonnull data captures current DWORD length
plus one and repeats the getter before the real size/gate decision. Large
sizes (`>=150`) free through current CRT regardless of the small-return gate;
disabled small returns skip the ring/critical-section return, with no extra
free or header reset. The existing actual-storage adapter remains unchanged.

Per-type release retains every native arm and ordered write:

| Tag | Owned operation before common reset |
|---|---|
| 2 | Nonnull `+C`: actual canonical free, then `+C=0` |
| 5 | Nonnull `+1C`: actual canonical free, then `+1C=0`; always `+18=0` |
| 6 | Nonnull `+C`: complete bag scalar with flags `1`, then `+C=0` after return |
| 8 through 11 | Accepted complete array provider on actual record `+20` |
| All others, including 7 | No owned release |

The common stores remain distinct and ordered `+4`, `+C`, `+28`, `+8`, at
Source offsets `F3`, `103`, `113`, `123`. The earlier nonnull `+C` stores
remain at `5E` and `D6`. The array provider retains its exact 39-byte body and
its own repeated pointer resets; its `+24` field is a DWORD byte count.
Record `+28` is reset without being freed. No other record fields or child
owner backlinks are cleared. Phase destruction writes actual `CE89D4` at
Source `+10`, then tail-jumps to the complete release body at `+14`.

Both 39-byte scalar bodies call their full destructor at `+0B` **before**
testing flags at `+13`. Only the low bit permits the real free at `+1A`.
They return the original root bits from the retained register at `+22`,
without reloading a freed root. Other flags bits do not suppress destruction
or independently permit a root free.

The 72-byte bag destructor publishes `D16504` at `+11`, calls the complete
map clear at `+21` on actual bag `+4`, publishes `D162C4` to the same map at
`+36`, and makes a second actual complete clear `CALL +3D` unconditionally.
It frees neither the root nor the borrowed map interior. Bag ordinal `+10C`
and non-owning backlink `+110` remain unchanged.

## Admitted ownership and ABI

Supply genuine live raw61 bags and accepted record-producer allocations,
including the real raw58/type-6 attachment and real empty-child clone outputs.
Mapped record, child and node owning edges must be finite, unshared and
acyclic, with enough stack for recursion. Child backlinks are non-owning.
Actual populated maps can be produced with the accepted genuine lookup and
new-node publication path; no populated clone or fake fixture is assumed.
Roots, keys and value buffers must not overlap one another or active frames.

Complete explicit canonical CC8A30 startup before constructing the context.
Use that same actual E175B0 pool and E188B4 allocator list, never E17540,
E175E8 or 0109DBF0. A nonzero cached atexit registration status retains the
constructed pool without a callback; a thrown startup is unusable. Each
node is a unique live aligned `14h` slot with valid allocator-owned page
identity, coherent page/table/free-stack membership and room for its return.
Do not independently reset allocator metadata or return a slot twice.

Keep the canonical cells/processes, actual key storage, initialized pool/list,
slots, roots and context alive through their uses. Enabled small key returns
require the same live pool generation that allocated the key and valid ring
indices/capacity. Preserve the real disabled-return gate, without treating it
as permission to destroy graph storage early. Finish all payload/key/node
lifetimes before CD9260 frees property-pool pages. Retain existing canonical
process and CRT callback ordering.

Freed roots and value/array blocks are genuine bases in the same current CRT
allocation/free domain. Never free borrowed data, a stack object, an Original
process heap allocation, a pool slot or the embedded map interior. There is
no concurrent graph mutation, trim, callback reentry, overflow, fault, failed
allocation or exceptional unwind in the admitted ordinary successful domain.
No rollback, cycle collector, count-zero shortcut or extra free policy is added.

These are ordinary context-bearing Win32 C++ interfaces. The scalars return
`std::uint32_t` root bits. Original scalars instead receive ECX/stack flags,
preserve ESI and use `RET 4`; the Source bodies use their complete ordinary
stack interface and plain `RET`. Original bag destruction also installs and
restores its FS/SEH frame. This packet does not supply that transport,
Original class/vtable ABI, exception cleanup, register/flags identity,
historical CRT compatibility or a binary replacement. No naked scalar or
hidden context bridge is used.

# Canonical locale textual operation

The existing canonical locale owner now composes the admitted textual-option1
parser with its own actual allocation and initialized pool. A direct parser call
outside this owner could leave the canonical owner marked initialized after a
partial failure. The new explicit operation records that history and blocks
drain or retry after failure. It grants no loaded-manager or consumer permission.

The operation proves the VFS application's actual stored host/data identities
through a pure metadata getter and compares all three actual raw string-cell
addresses. The completed owning input, its disjoint storage and genuine retained
renderer decrement cell remain caller prerequisites. No semantic container,
new native owner, callback provider or guessed input construction is introduced.

Private preparing/active phases precede bookkeeping and provider calls. Each
stable attempt declares its immutable actual TextualContext before its retained
TextualFrame, and is linked before parser effects. Returned construction/call
history is captured before healthy fences. Only private normal completion lets
the owner return to its initialized state; append-only history remains retained.

Input ownership transfers only at actual parser entry. Preparation failure leaves
the caller's input unconsumed and the owner failed. Escapes retain unresolved
input/file/record/provider state; no automatic return, retry, receiver free or
publication repair is added. Ended input/path/key/stream identities are never
followed by later history checks or metadata destruction.

Bind/init/borrow and predrain/delete/postdrain gates check quiescent private
operation history. Once a textual call is attempted, conservative derived debt
requires the Core-captured CFF140 route, including genuine 73CAF0/73C9F0 map
retirement. CFEA5C base-only retirement is rejected before its target. Existing
flags-reference forwarding, late flag sampling, matched free and flags0 debt
remain unchanged. No mapcount inference or post-free receiver read is used.

and evidence. Existing parser/native helpers, Core dispatch, host and CMake
registration remain unchanged. Exact pins, independent reviews and build/link

## Original ABI and required borrowed domain

`00AC5600`: ECX is the actual output8h header; the stack contains a **by-value8h** raw name header. It returns that output in EAX and uses `RET8`. The by-value header is adopted on entry and consumed by the callee. It is not a borrowed page's name. `00AC5770`: ECX is the actual page; the stack contains the output pointer; EAX returns output and `RET4` consumes that pointer. It first copies the current raw name at page `+100h`, then transfers that exact local8h header to AC5600.

`NativeGuiScriptPathContext` requires the existing `NativeStringRawPoolContext&` and the actual literal byte views at `D5CB18` (`interface/`, including NUL) and `CFD2C8` (`.lua`, including NUL). There are no default literals, `std::string` path shortcuts, semantic allocator overloads, invented cells, second pool, manager registration, or callback stubs. Both bodies call the established actual raw resize/concat/getter/return implementations. The provider must keep the same publication/gate/raw-manager cells and literals alive. A surrounding Lua adapter must also borrow those same raw cells; this file cannot inspect the private identity of an arbitrary `ActualNativeStringPoolStorage` or widen its `noexcept` release contract.

The new Source signatures additionally take persistent `NativeGuiScriptPathFrame` or `NativeGuiLayerScriptPathFrame` references. A fresh-frame rejection happens **before adoption or raw effects**; on that rejection the caller still owns the input. Once admitted, the same frame records actual input/output identities, its raw suffix/prefix/join headers, cached prefix data, remaining unwind state, and output ownership. The wrapper frame owns its copied header and nested callee frame. No copy, reset, retry, resume-cleanup or owner-release API is provided.

These frames have **no implicit cleanup and no destructor refusal**. After any entered failure the caller must retain the same frame and borrowed runtime domain until process exit; `requires_process_retention()` exposes that contract. The enclosing continuation/host must guard its whole graph before unwinding or destroying dependencies. Calls and raw-domain mutation are externally serialized. Frame initialization/residency, fresh-frame exceptions, and successful output-handoff metadata are Source contracts, not exact Original private stack-byte or allocation observations. The translation unit explicitly requires MSVC Win32 x86 and 4-byte pointers.

## Header and cleanup schedule

AC5600 owns the by-value input before suffix resize. It clears the suffix header, resizes to 4 with preserve1, then copies current length+1 from the required suffix view if current data is nonnull. It next owns suffix, clears/resizes prefix to 10, captures prefix data **before** its literal copy, and copies current length+1. Raw concat1 joins prefix and the actual by-value input into its local header; raw concat2 appends suffix into the actual output. Both use the existing `4261A0` actual-pool overload, including its current reloads and output-failure ownership.

Only after concat2 returns does AC56CA arm output bit1. Normal cleanup consumes join, prefix, suffix, then input. Join data is read before output arming; prefix uses the pointer cached at AC567C but its current length at AC56F9. Suffix data is reread after prefix return, and input data is reread after suffix return. Each nonnull return captures wrapping length+1 before resolving the real current `419CC0` getter and calling `BD1510`, including large-block or disabled-small-return domains. Headers are not cleared by destruction. The Source code uses overlap-safe copies and the existing zero-byte-copy omission; it does not snapshot caller headers around raw callees.

EH handler CB8899 points to `DEF83C`, maxState5, unwind map `DEF860`: `0 -> (-1, CB8880)`, `1 -> (0, CB8860)`, `2 -> (1, CB8868)`, `3 -> (2, CB8870)`, `4 -> (3, CB8878)`. Input/suffix/prefix/join funclets pass EBP `+4/-24/-1C/-14` to `41DD20`, which rereads their actual current headers. CB8880 tests output bit1 and clears it **before** loading output at EBP-28 and calling `41DD20`.

Source unwind consumes each map action before its potentially throwing getter. If cleanup itself throws, that newer C++ exception escapes and remaining lower actions stay recorded in the same failed frame, with no retry. This policy is explicitly **not** private Native FH3, double-exception, SEH, arbitrary private-frame alias, or binary replacement ABI equivalence. A failed state of -1 does not authorize retirement: the just-consumed cleanup may have thrown before returning its block. Successful Source handoff sets its metadata unowned/complete without writing the output header; Original returns with its private output bit still set.

The wrapper compares its local/source identities before clearing the local, resizes from current page length, rereads page length afterward, then reads copied count, current source data, and current destination data in assembly order. It adds no cleanup before transfer and never repeats the nested callee's consumed input cleanup. Its persistent frame preserves the partial copy/transfer metadata if Source entry fails; this is not an invented Original wrapper exception handler.

## Conventions

- Objects are the image's raw layouts, read and written at byte offsets
  (`read_field` / `write_field`). Every call the image makes is a named host
  method (`HudOrderCommandHost`, `OptionsScreenHost`, `MenuMiscHost` and the
  smaller hosts) invoked at the same point with the same arguments.
- NativeString temporaries the image builds on the stack (0041DD40 + memcpy,
  0041E870, 00426060, 004261A0 / 004263B0 concatenation) and returns to the
  sized pool (00419CC0 / 00BD1510) are folded into host methods that take
  `std::string_view`; the host builds, passes and releases the string. The
  NativeString assignments inside 005F52C0 and 005FDD90 are kept as explicit
  0041DD40 + memcpy calls because they write the destination object.
- Prompts are 00425D10 then 00531B00 with the ten arguments in
  `frontend_prompts.hpp` order (slot, message, kind, callback, unused flag,
  title, timeout, timeout result, countdown key by value, dismissible).
- Stack session messages (005FA9F0, 005FAAE0, 005FACB0) are built in a local
  24h-byte buffer exactly as the image lays them out (0075B430 base, +4h = 1,
  the class vtable, the zero bytes) and routed through 0077C2A0; the image
  runs no destructor on them.
- Slider positions (005F4C90, 005F4FA0, 005F5070) use `_ftol` of
  `float * 10.0 + 0.5`; the image computes in 80-bit x87, the C++ in double
  (difference only at exact rounding boundaries).

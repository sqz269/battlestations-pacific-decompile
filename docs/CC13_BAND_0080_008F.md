## Fixups

### F1. 0078C400 is the NetworkPacketStatistics constructor

`BSP_Application_Initialize` tests `[00F871B4] == 0` at `0073DD31`, allocates `7649B4h` bytes and
calls `0078C400` with ECX = the new block (`0073DD5B`). The body calls the singleton base
`00787B60` (`BSP_NetworkPacketStatistics_ConstructSingletonBase`), installs vtable `00D04388`,
constructs 2002 per-message records (stride `EF4h`, each `EFh` x `10h` entries through
`vector_constructor_iterator`, `+EF0h = 20000`), 5005 16-byte slots (`+0Ch = 9999`), an STL tree
head at `+762908h` and a critical section at `+7628FCh`, then registers message types `C1h`, `C2h`,
`AEh`, ...

The tag row in `config/tags/00780000.jsonl` was a `rename` row (`CG_array_ctor_helper_0078c400`,
evidence `e0031`). It is now an `action: "reviewed"` row named `BSP_NetworkPacketStatistics_Construct`
with the evidence key `cc13_sweep8E_packet_stats_ctor` in `config/tags/evidence.json`, and the ledger
name is applied in Ghidra (commit `c7e9d1e59`).

### F2. 00A41300 and 00782880 are sibling overrides of one virtual

| vtable | class (existing names) | slot +4 | slot +8 | slot +28h |
|---|---|---|---|---|
| `00D042A0` | abstract client | `00782880` | `007857F0` | `_purecall` |
| `00D24448` | XLive client | `00782880` | `007857F0` | `00A41660` `BSP_MNetworkClientXLive_Open` |
| `00D24390` | abstract server | `00A41300` | `007857F0` | `_purecall` |
| `00D243EC` | XLive server | `00A41300` | `00A422C0` `..._RemovePeer` | `00A41D80` `BSP_MNetworkServerXLive_StartHosting` |

All four share slot `+8 = 007857F0` below their overrides, so slot +4 is declared in a common root
class. The client branch and the server branch each override it once; the two bodies are byte
identical (`PUSH ESI; MOV ESI,ECX; CALL [vtbl+28h]; MOV [ESI+9Ch],2; POP ESI; RET`) but were not
folded. They are therefore the same virtual, not a base/derived pair. The client name
`BSP_MNetworkClient_OpenAndSetState2` stands. The A1 name `BSP_MNetworkXLive_ShutdownToState2` was
wrong twice: the function is the abstract **server** class's, and its +28h starts hosting rather than
shutting down. It is now `BSP_MNetworkServer_StartHostingAndSetState2` (`--replace`; the old record
stays in git history). The slot's own meaning ("start, then enter state 2") is a hypothesis; state 2
itself was not decoded. `docs/CC13_BAND_0074_0078.md` open question 4 still carries the old name.

  rows); every selected handler is used by exactly one row.

  It is now a reviewed row (`cc13_sweep8E_map_ping_send`). The other 65 bookmarks were not reviewed.

## Contract and ABI

Capture actual tree.head at +4, then head.left at +0 unconditionally.
The actual full-range provider 006A6A20 receives the same tree as both
owners, captured left/head endpoints and a private ignored eight-byte
output. Source uses its existing real NativeInputControllerTreeIterator
carrier and forwards the borrowed NativeStringRawPoolContext unchanged.

After child success reload CURRENT head, capture it for current CRT free,
clear tree+4 BEFORE tree+8 and return DWORD zero. A child exception retains
its progress and prevents this entry's free/stores. No count shortcut,
empty/null guard, key cleanup, rollback, retry or local EH is introduced.
There is no direct opaque0 access; admitted raw aliases can still overlap it.

Native ECX is the actual 12-byte tree, incoming EDX unconsumed, no stacked
inputs, plain RET, EAX zero before public stores. Source is uint32 fastcall
(tree, unused_edx, borrowedRawCtx), so the context adds Source RET4.
Child unused EDX is canonical zero, not original register residue.
Actual emitted Source zeros EAX AFTER the public stores, preserving the
semantic result without original register/flag timing equivalence.

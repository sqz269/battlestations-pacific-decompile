The implementation surface is appropriately closed: three additive qualified entries and private compile-time-selected kernels in the existing retirement header/implementation, plus two evidence files. No broad Host stub, provider abstraction or extra allocation is needed.

Each lexical handler must retain its own frame/sidecar references and trivial eligibility/home state. Retain incoming failure observations first. An unarmed handler bare-rethrows. An armed handler demotes before action entry; if the action returns, record only action completion and bare-rethrow the same incoming exception. Do not resume normal suffixes, pop failure frames or mark the body completed. If cleanup throws, retain its distinct stage/captured custody and rethrow that escaping secondary exception without retry. Outer still-armed handlers may run their own actions against their own saved homes. Passive flags do not retain either exception object's identity or guarantee the primary reaches the root after secondary escape. No replacement exception, nested wrapping, success conversion, forced termination or Original secondary-terminal policy is justified.

Metadata/domain rejection is an ordinary returned non-completion, not a Native exception.

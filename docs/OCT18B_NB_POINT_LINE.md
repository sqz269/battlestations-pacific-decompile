# Point-array polyline distance to a line: 007AE930

The complete 986-byte body at `007AE930..007AED09` is reconstructed as `point3_ptr_array_distance_to_line_007ae930` in the existing Path/MovCam family. Its 280 native instructions retain their x87, branch and checked-array-load order. The name is a hypothesis. Its sole recovered caller is an undefined body at `007B07F0`, call site `007B08E9`; neighboring reconstructed point-array operations at `007AE7B0` and `007AEEC0` establish the family.

The result is the minimum distance between the infinite query line and the pointer-array polyline. Each vertex supplies an endpoint distance. Each segment also supplies the closest distance between its infinite supporting line and the query line; that candidate replaces the minimum only when its closest point lies within the segment. A single-point input returns its point-to-line distance. The native invalid-parameter calls remain calls with their original continuation, including the subsequent native pointer reads if a handler returns; no neutral empty-array result is invented.

The original interface is `ECX = actual array`, stack `(origin*, direction*)`, `ST0 = float minimum`, `RET 8`. Actual array words `+08h/+0Ch` hold the checked pointer-vector begin/end. The source adds a borrowed immutable target table in EDX. It reserves 16 additional frame-tail bytes and saves EBP there, using EBP for that table. Original locals keep every offset and call sites preserve their stack alignment modulo 16. The original argument loads at `007AE939` and `007AE9C5` change from `+98h/+94h` to `+A8h/+A4h`; the frame allocation/release changes from `84h` to `94h`. EBP is restored before return. Every other original instruction retains its order, with local jump labels, MASM memory-type spelling and explicit target-slot calls replacing address notation.

The seven required targets are existing geometry, checked-vector and CRT bindings. Their bodies are not reconstructed or stubbed here. The table must remain valid and immutable throughout the call, and each target must satisfy its original register, stack cleanup, return and callee-saved-register contracts.

# A2 startup preload candidate

`kNativeShaderPreloadStartupCc16Bound` is OFF. The candidate links genuine
existing factory, sampler, effect and73BF80 implementations into the startup
owner graph. A1 remains ON and Page activation stays OFF. No new native body or
binary ABI credit is claimed.

When enabled, the host installs one GameNativeMissionFactories before calling
its real BBCB40 setup at the73D8CC position, after core VFS phase2 and before
platform construction or the later archive tail. The genuine registry must be
absent/empty; its existing facade verifies the four sorted direct insertions.
Raw VFS/string/owner services are already real here; no archive FileBlock scope
or fabricated registry is used. Creation is not replayable.

The renderer borrows that owner before construction. At73DD12, after shadow
startup, a retained StartupShaderPreload owns the genuine sampler, effect facade
and MissionShipShaderPreloadGraph. The sampler borrows the one input core's
metadata; native input publication/startup remain at73DD8E. The existing graph
runs73BF80 with the canonical startup Application at E1AE90, its real08h rows,
the real Lua/VFS/material domains and its complete shader-cache bracket. No
temporary diagnostics, empty bracket or early Text/scene creation is copied
from the old failed trial.

Mission preparation borrows the same factory/preload pair when present. Its
legacy owning path is retained when A2 is absent. A borrowed mission never
creates, retires or acknowledges the shared factory/preload; it detaches both
views when closing, including its never-prepared early return. Lookup admission
is rechecked at renderer binding, startup preload and mission preparation.

The Application shutdown releases any late mission model cache first, then
the startup preload rows. Renderer drain retires mission consumers, the startup
preload and finally the shared factory table before raw singleton shutdown.
Font/GUI borrowers have already retired at the host boundary. After native
drain, renderer state becomes drained before effect/sampler closure can reenter
its closure check. The renderer detaches its factory borrow only after the
complete outer closure returns. The host then acknowledges factory parent drain
and releases its metadata while the singleton host, VFS and data still live.

The host's common drain helper covers normal shutdown, destructor shutdown and
the renderer-absent path. Entered setup/retirement/drain/closure failure exits
the process while retaining the entire provider graph. BBC5D0 leaves dangling
table bits until parent drain, so the facade's retired-state retention result
cannot authorize provider destruction. No owner is dropped on retirement alone.
Explicit host phases and detached borrows prevent repeated factory retirement.

Root and independent source review pass after correcting stale mission borrows
in both closure paths and guarding repeat post-retirement row release. Integrated
OFF/ON build/runtime gates are in progress. The initial OFF Win32 build passed
both existing CTests; later corrections require the frozen rebuild. No runtime, startup timing,
queued-callback, shader-resource completeness, allocator/reload, raw Text/Icon
or full frontend/rendering proof is accepted yet.

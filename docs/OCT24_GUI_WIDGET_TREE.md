# Closed raw GUI widget tree lifetime transport

`NativeGuiWidgetLifetimeDispatch` now optionally admits full raw Text and raw
Icon children alongside its existing Group/ClipBox domain. It retains ONE
lifetime context, the SAME actual-owner registry and the original raw links.
No Page, host, manager, FE_initial tree or actual GUI application is activated.
This is a source prerequisite for a Group/two-Icons/Text hierarchy, not proof
that the full Page/service graph has been composed or run.

The GUI widget Group here is D5CB80 with the actual EC payload/F0 slot. It is
distinct from renderer cGroup D634F8 and creates no renderer node owner.

## Enabled native profiles

The existing profile aggregate appends two default-null table borrows. Null
keeps that class outside the closed domain; existing two-field Group/ClipBox
callers retain their admissions. Supplied tables are genuine stable actual
native data, at least9 DWORDs. Constructor checks the selected0/4/C/20 cells:

| Raw class/profile | current0 | deleting04 | class0C | scene20 |
|---|---|---|---|---|
| Group D5CB80 | BD30E0 | AC73E0 | AC6F70 | AA8320 |
| ClipBox D5D058 | BD30E0 | ACE620 | ACE0C0 | AA8320 |
| Text D5C6C8, optional | BD30E0 | AB8EE0 | AB83D0 | AA8320 |
| Icon D5C4C0, optional | BD30E0 | AB6100 | AA1CC0 | AA8320 |

No table is copied, synthesized or used as a callable host vtable. A captured
profile must match its canonical dynamic class, with its optional table enabled.
Unknown profiles/classes, mismatched targets and disabled admissions reject.
The dispatcher does not add Grid/Curve/Line/AnimIcon/Progbar or all18 support.

## Same canonical metadata and construction custody

Text must be the full `NativeGuiTextReference` bound by canonical122 over the
completed actual1F4 construction93. The Step1 eight-byte
`NativeGuiTextIdentityReference` and logical GUI owners are excluded. Bound
phase is checked before borrowing any raw fields or table. Its existing
`storage_context()` must name the SAME registry and `retirement.base` context,
with the SAME construction lifetime and section/resource services.

The retained93 record must still report started/complete base, derived and
sections, destination equal to this actual object, native state6, and no
constructor cleanup/failure/base-lifetime end. The supplied Text table must be
the SAME genuine Original-VA alias from that canonical122's read-only data
service. These are metadata/custody checks, not another count or native retain.

Icon must be its full `NativeGuiIconReference`, found canonically in that SAME
registry, with the SAME actual identity and lifetime context. Retired, failed
or destruction-entered metadata reject. The existing metadata API identifies
the bound phase without adding a getter or reading a native count/profile:
`!retired() && !failed() && !destruction().started`. Serialized existing scalar
entry has no callback between consuming its private phase and starting that
destruction frame, so a destructive callback cannot pass this guard.

These checks do not prove arbitrary raw allocation provenance, complete backing,
type startup or transitive provider lifetime. The producer retains all of those
independently, keeps metadata stable, and stops using the graph after an entered
failure. A failed provider may already have ended a payload lifetime; the
dispatcher never rediscovers fields or a count to determine that afterward.

## Genuine class query and scene release

AB83D0 is40 bytes83D0..83F7: ECX unused, stacked descriptor DWORD, AL result,
RET4. It reads CURRENT F8BE28/2C/30 in order and stops on the first match.
AA1CC0 has the same schedule over CURRENT F8BDD8/DC/E0, through1CE5. The words
at F8BE34/F8BDE4 are outside those three-ID ranges. Neither body compares a
fixed GUI widget-type enum.

`NativeGuiWidgetLifetimeRequiredCalls::call_class_query_0c` remains mandatory
and now accepts the selected Text/Icon targets too. It must supply the genuine
initialized actual lineage/type phase and preserve current ordered short-circuit
reads. Text is not replaced by descriptor equality or unconditional true; Icon
is not replaced by false. This packet supplies no type initializer or fallback.

AA8320 remains the exact scene body for every admitted class. Its existing
schedule captures the class-slot address before the genuine AB6A30 descriptor
read, then loads the CURRENT slot target. A true Text result runs AB73B0 on
actual188, then normal scene release uses actual4C. No derived field is guessed
from the companion's C++ class. The exact native query controls that branch.

## Native scalar and raw-tree authority

The selected child04 call always receives native flags1. Text uses its real
`delete_current_scalar_00ab8ee0`, Icon its real `delete_scalar_00ab6100`; existing
Group/ClipBox transports are unchanged. These are direct deleting calls with
no extra actual+04 count gate/decrement, protective retain or delayed callback.
Each canonical owner supplies its existing persistent frame and genuine derived,
base and matching-pool schedules. Text/Icon failures keep their existing failed
canonical binding; this dispatcher propagates failure and adds no cleanup.

A successful Text scalar may dispose its own companion. There is no companion,
raw payload or count access after any selected scalar returns. The captured
pointer is used only to make that one call, then discarded.

During full Text/Icon retirement, raw AA9730 publishes its base D5C130 before
its own AA8320. The existing raw lifetime body handles that genuine base table
directly. It does not re-admit a retiring owner as bound Text/Icon. Children
must independently be in an admitted live canonical phase. Existing owner
failure policies and base/member unwind remain authoritative and unchanged.

Raw AA9730 still performs self-detachment and the real A9BD50 remove-all.
No AA83A0 pre-detach, manual link erasure, child-count adjustment or progress
fallback is added. Child loops retain their native reload order. Text's real
glyph-child113 transport can use the same dispatcher only when every reached
raw widget is independently in this enabled canonical domain with its genuine
prepared lifetime graph; unknown/prefix/model companions are not substituted.

Timed entries still require their genuine current table and deleting target.
Canonical counted owners cannot be reclassified as timed entries, and unknown
unregistered allocations must be rejected by the mandatory timed provider.
The timed remaining-time word at+04 is never treated as a reference count.

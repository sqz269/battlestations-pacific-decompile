00A50000-00BFFFFF, tag library copies, reconstruct an anchored spine, and list the gameplay left for
cc9. 00A00000-00A4FFFF belongs to cc13-sweepA1 (docs/CC13_BAND_00A1_00A4.md) and was not touched.

## Method

1. `python tools/template_shapes/st1_shapes.py 59 ... 97`, then `st1_auto.py`, `st1_rules.py`,
   `st1_family.py`, then `st1_build.py --range 00900000 00A00000 --write` and
   `--range 00A50000 00C00000 --write`, then `st1_apply.py 0 1000` under `ghidra_lock`. For the
   gameplay bands a 2-hour lease (`cc13-sweep9x-stl`) covered 0090-0097 and 0099-009F around
   cc9-gunnery36's leased addresses (0099DF87, 0099E127, 009C659F, 009C6678, 009C6929); it was
   released after the tag commit. Only template copies were tagged there.
2. Per band: `local/s9x_feat.py` (Capstone over the disk image: size, callers, named callees, import
   calls, strings, float constants), `local/s9x_vtm.py` (vtable membership, copied from
   cc13-sweep8E), `bsp.py docs-for`/doc greps, and compact live decompiles (`local/s9x_dec.py`).
3. `local/s9x_pools.py` finds Mit pool-allocator families (Allocate = EnterCS + operator_new + an
   InitBlock + LeaveCS; Free = Enter/LeaveCS only; Construct = InitializeCS + operator_new;
   Destroy = DeleteCS; Trim = the 160-byte free loop). The class comes from whoever calls the Free
   (a deleting destructor) or the Allocate. `local/s9x_poolrows.py` writes the family rows.
4. `local/s9x_mech.py` names single-callee wrappers mechanically: PushBack (doubling growth through
   a named `*Reserve*`), Clear (`*_Resize(0)`), iterator thunks, `_Tree` construct/clear. 57 rows,
   each with exactly one named callee; samples were decompiled to confirm the shape.
5. `local/s9x_apply.py` (adapted from cc13-sweep8E): `STL_` rows become `stl_shape` tag rows,
   everything else goes through `bsp.py ledger add-name`; then `ghidra_annotate.py --apply
   --addresses ...` and `st1_apply.py`.

`tools/template_shapes/st1_retag.py` now takes `--source DOC` (default unchanged,
`docs/CC13_BAND_006D_006F.md`), as cc13-sweep60 asked in docs/CC13_BAND_0060_0066.md.

## Reconstruction (`src/band_0090_cc13.cpp`, `include/bsp/band_0090_cc13.hpp`)

Reconstructed, build-tested; new C++ interfaces, not binary replacements.

- **0098DF90 `recommend_detail_level`.** Memory (+2Ch) must exceed 499 and CPU MHz (+30h) 63Fh,
  else 0. GPU row (+28h) -1 means the 'Unknown' row 0, allowed only when +20h is above 100h. Score 0
  gives 0. Tiers: memory 1 (<201h), 2 (<1000), 3; CPU 1 (<9C4h), 2 (<C80h), 3. The listing
  (0098E04A..0098E082) computes `float(cpu*1.6 + mem*0.5 + score*0.9)`, then `/3.0` to float, and
  returns 1 below 1.5, 2 below 2.5, else 3. Constants read from the image: 00CE3D48 = 1.6f widened,
  00D7A280 = 0.5, 00D7A390 = 0.9f widened, 00D7A2B0 = 3.0, 00CE380C = 1.5f, 00CF87C8 = 2.5f.
- **0098E910 `build_default_options_text`** (with 0098E0E0 `supports_display_mode`). The options
  file text, in order: `fullscreen 1`, `Resolution w h` (640x480; level 1 800x600; level 2
  1024x768; level 3 1280x1024 else 1024x768, each only when the mode list holds it), `Vsync 1`,
  `ShaderModel` (+24h), `Antialias` (last entry of +14h/+18h at level 3, else 0), `Clouds 1`,
  `Foliage` (level 3), `Shadow`/`Reflection`/`OceanDetail` (1 from level 2), `TextureDetail` /
  `ObjectDetail` (2 from level 2), `SoundEnabled` (00F8A0E0), `Language` from the LCID at +C38h
  (407h deutsch, 40Ch francais, 410h italiano, 415h polski, 419h russian, else english).
- **00BB9F40 / 00BBA030** CRC-32 (reflected, EDB88320h); 00BBBAB0 applies NOT before and after.
- **00A77860 `set_dialog_target_level`**: FSUB, FSTP float, FMUL double 0.5, FSTP float,
  AND 7FFFFFFFh (assembly read).

No call site was rewired; nothing in the host calls these yet. `scripts/build.ps1` passes
(configure, build, 2/2 tests).

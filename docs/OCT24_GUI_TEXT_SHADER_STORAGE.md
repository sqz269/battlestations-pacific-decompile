# Actual Text shader storage prerequisite

`ensure_native_gui_text_font_shader_storage_00ab8ce0` supplies the normal
`AB8CE0..AB8E6C` body (397 bytes, 118 instructions) on the SAME full raw Text
allocation already completed by constructor93 and bound by canonical122.
Native ABI is ECX Text, no stack arguments, plain `RET`, AL selection attempted.
The new C++ interface is not a binary/private-stack/FH3/SEH replacement.

This is a concrete prerequisite for nonempty `ABA8D0`: the installed
`interface/fe_initial.lua` active `press_start_Text` specifies `Viper19` and a
nonempty `DefaultText`. Existing `AB8CE0` composition uses `GuiTextLifetime`
fields; this API instead reads actual Text+108, +1C0 and +1EC. It creates no
Text, Model, native count, registry, effect cache, shader or second field owner.

1. A nonnull actual1EC returns false before native name, configuration, Font or
   renderer reads. Source metadata admission adds no native effect.
2. Construct the actual8B empty comparison header using original literal
   `CE3A0C` and existing raw41E870. Compare actual1C0 with existing raw449AF0.
   Capture comparison data once; if nonnull, read current length and return it
   through current419CC0/BD1510. This wrapper has no outer armed unwind state.
3. A nonempty override passes the SAME Text1C0 header to current renderer48.
   It does not create a copied name or run configuration/Font selection.
4. Otherwise capture the SAME actual0109CF04 publication and execute native
   SSE `CVTSI2SS` on its signed DWORD+28. Compare ordered-equal with the genuine
   read-only `D5C56C` float720 using `UCOMISS/LAHF/TEST AH,44h` parity. Only on
   this match read actual Font108, verify image custody/domain, then compare its
   actual+18 bits with the live one cell using the native SSE sequence. No
   descriptor metric or copied scale is consulted.
5. Use raw41E870 on the reached actual header: header0 (reusing the empty
   wrapper) for `D5C794` `GuiFont.mshd`, or header1 for `CEFD78`
   `GuiFontBilinear.mshd`. Headers are persistent eight-byte native storage,
   not semantic string objects or copied name adapters.
6. Capture current renderer, current profile and numeric slot48. Resolve its
   actual profile bytes through the existing `GameNativeReadOnlyData` and
   require returned pointer bits equal captured profile. Verified original
   `D5F0A8+48` contains `B318B0`. That target executes the existing real
   `load_native_renderer_material_effect_00b318b0` with the SAME effects context
   and retained acquisition record; no numeric original address is host-called.
   Any other reached target requires `unknown_renderer48` and its genuine body;
   an absent provider is an explicit unsupported boundary.
7. Transfer the returned owned effect credit into actual1EC without another
   retain, including a native null result. Override returns true. The point
   default arm captures name data before publication (`AB8DCF/AB8DD5`); the
   bilinear arm publishes before data capture (`AB8E1A/AB8E20`). Both disarm
   name state before current-length/getter/BD1510 cleanup and return true after
   successful cleanup. True means attempted, not load success.

The effect-cache `.mshd` to `.shfx` handling remains in its existing actual
loader. This packet neither creates another cache nor claims an Original
compiled-material file ABI. Returned shader credit belongs to Text1EC and its
existing retirement118. No old-shader release is invented for reentrant field

## Persistent frame and failure

Call with one `NativeGuiTextShaderStorageContext{font_resources,
NativePlatformLoadPublication(actual_configuration_cell), unknown_renderer48}`
and a fresh, independently retained `NativeGuiTextShaderStorageFrame`. Its two
actual8B headers and `NativeMaterialEffectCacheAcquired` exist before entry;
the four header words are deliberately uninitialized until native construction.
This is caller metadata/scratch, not another owner, cache or reference count.
The configuration borrow is the actual publication read for native+28, not the
effect loader's separate `ResourceLoadEventHost` adapter cell.

Keep the entire genuine93/118/122, actual renderer, Font images, cache/string/
VFS/compiler/Lua service graph and all transitive provider backing alive. The
existing effect-loader activation obligations are unchanged; this packet adds
no host activation or new Lua environment. Serialize publications/native
lifetime, prevent receiver retirement during remaining reads, and keep frame
backing separate from every raw/context/provider/resource/input region.
Known checks cannot prove opaque/transitive provenance or disjointness.
Reentrant calls require separately prepared retained frames.

The original handler at `CB7FF0` points to FuncInfo `DEEE20`: two entries in
unwind map `DEEE10` both transition to state-1. State0 calls `CB7FE0` for the
header at native EBP-1C; state1 calls `CB7FE8` for EBP-14; both tail raw41DD20.
Normal code arms these states only after capturing current renderer/profile/
target. The Source body preserves that timing, consumes state before cleanup,
and projects these two observed outer actions on C++ escape. Cleanup escape
terminates. A provider-boundary marker is not proof of native exception origin,
and this is not arbitrary native unwind/SEH/FP-exception equivalence.

Failure preserves reached raw publication and all unresolved cache acquisition
obligations. A nested load may acquire a caller credit and then fail before
return; the retained cache record, not a new inferred pointer/refcount, records
that obligation. No shader rollback or unpublished-credit release is added.
Unarmed constructed names remain retained if metadata fails before state0/1.
Consumed headers cannot be reread as owners. Keep the failed frame, SAME raw
backing and whole independent creator/provider graph; never reset, retry,
implicitly drain dependencies or rediscover lifetime from diagnostic pointers.
The frame destructor terminates for entered/failed calls rather than abandoning
the retained nested graph. Fresh and complete frames perform no native cleanup.

# B1B400 explicit-options sampler cache wrapper

`load_native_sampler_with_options_00b1b400` reconstructs the 193-byte normal body at `00B1B400..00B1B4C0` against the actual 1Ch-byte F8D420 loader and the existing orch5 `B1A4F0` cache entry. The installed PE SHA256 is `b682a82c52f81f957b2c70222077305a933f72481686c88843077f714b956dd6`; live Ghidra bytes at `00B1B400` match the installed 193-byte span SHA256 `3ea4ec8e1febb9ed4a0102ea5d6435ac0236a46399655c6f780e3d4f8030d5b4`. Primary evidence is `local/de-sampler-name-options-evidence.json` in the orch3 primary worktree, SHA256 `8026f96a39411edd63834ff279b1c231d8e2ad877066fa231f2f65450c61a67b`.

Original entry takes ECX complete loader, public stack name and options headers, returns EAX resource and uses `RET 8`. The source `__fastcall` keeps ECX and those two public stack words, adding EDX as `NativeSamplerOptionsWrapperContext`. Its naked adapter forwards addresses of the original public slots to a private body. That body captures the name at entry; it loads options from the public slot only after lowercase. The source context borrows the existing `NativeSamplerCacheEntryContext` and a caller-retained `NativeSamplerOptionsLoadOperation`, not a typed cache or callback substitute.

The body compares the actual temporary header address with captured input *before* zeroing both header words. For distinct headers it reads current input length for `0041DD40(preserve=1)`, then rereads current input length before capturing temporary data. On nonzero source length it reads current temporary length and current source data, and copies into that **captured** data. The temporary data capture is kept across lowercase and cache calls. Native state 0 arms only after the copy completes. `004BCC00` lowercases the actual temporary, then B1A4F0 receives complete owner+4, temporary, late options, and literal flags 1/1. On normal return the wrapper disarms state before checking captured data; a nonnull captured pointer is returned to the concrete current pool using the **current** temporary length plus one. EAX returns the cache result even if the pool callback changes the local diagnostic frame.

The recovered native state-0 unwind action `CBC730` tail-forwards `0041DD20` on the **current** temporary header. The source catch invokes the existing actual-pool `destroy_native_string_header_0041dd20` overload only after that state is armed. Initial resize/copy failure leaves the partial header unarmed and uncleaned, matching the native map. A failed B1A4F0 child remains in the persistent operation frame; the wrapper never acknowledges, replays, or silently discards it. The caller must resolve any failed child and any unarmed partial header before retiring the diagnostic frame. Normal completion leaves no local-name obligation.

The source frame's temporary header lives in caller-retained storage rather than the native EBP-14h slot. Native BF7680 is `_memcpy`; this source uses the existing orch5 host-CRT `std::memmove` contract and qualifies that comparison to nonoverlapping valid ranges. Native FH3/SEH and hardware faults, the exact game CRT/IAT exception identity, live profile-table/canonical-owner admission, and gameplay behavior are not established by this source. No resource release or missing-result fallback is added. The report pins the six original direct calls and provider hashes; `verify_report_calls.py`, the Win32 build, generated object review and existing CTests are recorded there.

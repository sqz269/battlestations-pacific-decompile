# Raw Text shadow preset storage: Source136

`apply_native_gui_text_shadow_storage_00ab72d0` supplies the whole normal
actual-storage payload of `[00AB72D0,00AB73A9)`,217 bytes/40 Original starts,
inclusive end73A8. The descriptive name is a hypothesis. Native ECX Text plus
one preset DWORD and RET4 becomes an ordinary Source API over the actual1F4
receiver, a mutable ordinary DWORD HOME, an explicit private16B spill frame and
four live constant roles. It is not an Original ABI replacement.

The preset HOME is read once before the first Text payload load. Equal current
Text+1D0 returns without stores or constant reads. A changed preset is written
to+1D0 before the captured -1 branch; -1 clears only BYTE+15C. Every other value
captures the live offset first, sets BYTE+15C, then interleaves each live default
color DWORD load with its corresponding Text+168/+16C/+170/+174 store. It writes
DWORD+160=0 and stores the captured offset at+164. No clamp or color snapshot.

Captured preset1 then loads ONE once and executes the four actual private SSE
spill stores/reloads in Native order. Text+168 is written before the live alpha
load; that alpha load precedes the Text+16C store, followed by the final two
stores. Explicit MOVSS/DWORD operations preserve widths and cached values.
There is no floating arithmetic, pair/quartet rewrite or helper while a value
is held. The Original body contains no x87 instruction and calls no callee.

The frame's user-provided constructor leaves all four ordinary Native words
unwritten, including under value-initialization. No Source phase, error or
authority framework is introduced. Source address carriers and control storage
are separate from Native write extents; the caller supplies genuine live Text,
valid physical C++ storage, declared operand alias domains and retained cells.
The Source frame is not an Original stack allocation or saved-register image.

Bind RO D5C5C0/D7A24C/CEE07C through the existing read-only owner and borrow the
same `game_native_gui_text_state().shadow_color_00e12fd8()` array. Binding takes
addresses only. It does not sample values, allocate another process role,
initialize/reset colors, create a Text pool, or add Native ownership. This leaf
does not touch the distinct F8BE38/F8BE48 MISColors defaults.

The existing semantic `apply_gui_text_shadow_preset_00ab72d0(GuiTextLifetime&,...)`
is unchanged. No actual Text is cast to GuiTextLifetime/GuiTextWidget/GuiWidgetOwner.
No profile/count/ready admission, callback, owner lookup, field-reader operation,
font/model service, cleanup, rollback or termination policy belongs in this leaf.

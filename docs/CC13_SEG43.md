# Segment 43 (cc13-seg43): multiplayer session, messages, recon level, MNetwork records

Packet cc13-seg43, segment 43 (0076AA00..00786C40). Code: `src/mp_seg43_cc13.cpp`,
`include/bsp/mp_seg43_cc13.hpp` (namespace `bsp::cc13_seg43`). Every row is reconstructed and
build-tested only: not ABI-compatible, not fixture-tested, not game-validated. Names are
hypotheses, not recovered symbols.

## Conventions

- Objects are the image's own storage addressed by byte offset (session = MMultiPlayer at
  game+1EF0h: mode +F4h, server transport +188h, client transport +18Ch, receive queue
  {+24Ch data, +250h count}). Session-message vtables are written as the image's constants.
- Calls into bodies not reconstructed here are named hook methods (`MpSeg43Hooks`, `RoleHooks`,
  `ListHooks`) invoked at the same point with the same arguments; virtual calls are hooks named
  by their slot. Some hooked callees have reconstructions elsewhere under other host models
  (0075B430 `native_session_message_base.cpp`, 007849C0 `native_game_embedded_lifetime.cpp`,
  00770750 `multiplayer_session_cc13.cpp`, 0077C2A0 `session_message_dispatch.cpp`, the bit-cursor
  bodies, 00484540 / 004837D0 unit-list bodies, 006952A0 / 00694A60 observer bodies); the hooks
  keep this file independent of those host models.
- Reconstructed here and called directly: the NativeString resize 0041DD40 and
  `NativeStringStorage::release` (the inlined 00419CC0 + 00BD1510 pair), and the Win32
  Enter/Leave/DeleteCriticalSection imports (00CE2218 / 00CE2210 / 00CE2214, names read from the
  hint/name table at 00E0568A).
- Global words are passed by reference (`MpGlobals`, `EntityRegistryGlobals`) so each read
  happens where the image reads it.
- Session-message send helpers the seg56 worker hooked: 0075B430 is used here only as a hook;
  0076A9F0 and 0077C2A0 are not reconstructed here (0077C2A0 is a hook in 0077C470).

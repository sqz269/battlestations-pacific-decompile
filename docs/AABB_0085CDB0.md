# 0085CDB0, the segment-versus-box slab test

Packet `cc9_aabb_0085cdb0`, cc9-platform2, 2026-09-25. Names are descriptive hypotheses, not
recovered symbols.

## 1. The routine

`BSP_Geometry_SegmentBoxHit` 0085CDB0 (no Ghidra export). Its interface:
- `__fastcall(float out[3] = ECX, const float min[3] = EDX, const float max[3], const float p0[3],
  const float p1[3])`, RET 0Ch, body 0085CDB0..0085D01A.
- It returns 1 in AL with `out` set, or 0.
- Its callers are 00929B80 `BSP_CollisionShape_TraceSegment_TransformedBox` and 0098B130
  `BSP_SpatialIndex_NearestUnitOnSegment`.

**The box** is two corners, `min` and `max`, in the caller's frame. Nothing is read from a physics
object inside 0085CDB0:
- 0098B130 passes a node's world AABB (`node+13Ch`/`+148h`, docs/SPATIAL_INDEX.md: 0098A750
  builds it as the oriented box's axis-aligned hull, `centre*M +- sum |M_i| e_i`);
- 00929B80 passes the physics-library box from DYN_physics_00C31F90, with both endpoints carried
  into the shape frame by `this+B0h`.

**The slab loop**, for each axis i with a = p0[i], b = p1[i] (0085CDEE..0085CF11):

| case | early out (return 0) | entry fraction | exit fraction |
| --- | --- | --- | --- |
| b <= a | max < b, or a < min | (max - a) / (b - a) when max < a, else 0 | (min - a) / (b - a) when min > b, else 1 |
| b > a | max < a, or b < min | (min - a) / (b - a) when a < min, else 0 | (max - a) / (b - a) when b > max, else 1 |

- The running entry starts at 0.0 and takes the maximum. The running exit starts at 1.0
  (00D7A24C) and takes the minimum. Once exit < entry the routine returns 0 (0085CF02).
- After three axes, `out = p0 + (p1 - p0) * entry` (0085CF19..0085CFAB).

**Edge cases.**
- A segment that starts inside the box hits at p0, with entry 0.
- A zero-length or axis-parallel segment reaches the division only when it lies inside that slab,
  and then neither fraction is computed. Outside the slab it has already returned 0.
- Touching counts: every bound test is inclusive.

**Precision (listing).**
- Each denominator `b - a` is rounded to float (0085CE33, 0085CE86) and reloaded. The numerator and
  the quotient are x87.
- Each fraction is stored to float before it meets the running entry and exit floats (0085CE51,
  0085CEC0, 0085CED4).
- The point's `p1 - p0`, the product and the sum are each stored to float.

**Reconstruction.** `bsp::segment_box_hit_0085cdb0` (`src/hit_narrowphase.cpp`, beside 0085CAD0)
uses double quotients rounded at the same stores.

  model box with its own slab loop (`line_of_fire_blocked_0072cdd0`). The image tests the node's
  **world AABB**, which is larger for a ship not aligned to the axes. It uses 0085CDB0, and its

# Band 00990000-009DFFFF: gameplay naming pass (cc13-gp99)

Packet cc13-gp99 named and tagged the raw `FUN_` functions (no tag, no ledger name) that
`tools/raw_ownership_cc13.py list cc9` assigns to cc9 in 00990000-009DFFFF, and reconstructed a few
anchored leaves in new files. It is a metadata pass: no cc9 host file was edited, nothing was wired
into a host, and no game was run. The method and tooling are those of docs/CC13_GP_009F_00A3.md
(scripts `local/gp99_*.py`, ignored).

(`python tools/bsp.py lookup <addr>` or the shards `config/names/00990000.jsonl` .. `009d0000.jsonl`).

## How the band is organised

The band is the plane bot-task system and the start of the ship AI.

- **Bot-task interface.** 26 bot-task vtables share the 26-slot interface of docs/BOT_TASKS.md. A
  census of the already named overrides gives the slot roles used for the new names: `+4h`
  DebugDraw, `+14h` GetName, `+18h` Describe, `+1Ch` break-off test, `+24h` release request,
  `+3Ch` CommandClass, `+40h` IsCommandStillValid, `+4Ch` WaitValue, `+50h` StepResult, `+54h`
  UpdateCruiseProfile, `+58h` Stop/Flush, `+5Ch` a static record, `+60h` Save, `+64h` Tick. The class
  of each table comes from its GetName string: base ("not defined"), Rocket, CloseToShip,
  DepthCharge, DropKamikaze, Kamikaze, Land, LevelBomb, "conditioned", "immelmann", "gainaltitude",
  stop, "pullup", "tightturn", "leavealone", "barrelroll", "flikflak", "split s", "moveonpath",
  "moveto" (two tables), DiveBomb, Retreat, Strafe, Takeoff, "torpedo". The dogfight table
  (`00D1F9B0`) overrides slots the census keys on and was mapped by hand.
- **Base slots.** `0099B6A0` (+24h release request), `0099C2C0` (+40h still-valid),
  `0099D060` (+60h save, "avoidFlags") and `009A1A90` (+18h describe) are the base bodies shared by
  most tasks.
- **Task factories.** `0099EBB0` registers each factory on the list `00F8A314`, `0099EBE0` unlinks it,
  `0099C690` finds one by name (counted string, `__stricmp`), and `0099AA20` loads a pilot bot's tasks
  through them. Each factory's slot 1 (`..._Factory_Create`) allocates the task and runs its
  `ConstructFromStream`, which starts with `0099C8B0` (the stream counterpart of
  `BSP_BotTask_ConstructBase`).
- **Bot conditions** (`00996xxx`). Four-slot classes (Test, deleting destructor, Load, Save):
  "simpletimed", "timed" (decorating another condition), and the target conditions "turnAway"
  (`BSP_BotCondition_PointOffNose_Test`), "turnToHdg", "turnTo" and "farAway"
  (`BSP_BotCondition_PointDistance_Test`). `009968D0` builds a condition from an archive by name.
  The "conditioned" maneuver task holds one at +3F8h and retires when it fires (`009B93D0`).
- **Ship AI** (`009D5xxx`-`009DFxxx`): path-node walks and the two path-arm override bytes
  (`009D5AE0`, `009D5B90`, docs/SHIP_AI_RING_WINNER.md), the steering backup pair
  (`009DDBC0` save / `009DA0D0` restore), the torpedo warning timer (`009DA8D0`), observer-member
  destructors and a set of debug-draw helpers.

## Findings

- **The avoid-flag description keeps one name.** `009A1A90` calls `BSP_CharacterString_AssignCounted`
  three times on the same destination (`MOV ECX,ESI` at `009A1AE0`, `009A1AFB`, `009A1B12`), so a
  later set bit replaces the earlier text: with several flags set only "AV_TERR" (bit 0), else
  "AV_VEH " (bit 1), else "AV_GUN " (bit 2) survives. Debug text only.
- **Tightturn is built on pullup.** `009BAFC0` installs the pullup vtable `00D20568`; the tightturn
  builders (`BSP_BotTask_MakeTightTurn`, `009BB380`) overwrite it with `00D205E0`, and the tightturn
  save `009B9FD0` extends the pullup save `009B9F20`. Barrelroll is built the same way (`009BB770`).
- **Dive-bomb step result.** `009C8290` answers 2 in the state at +734h, 0 in the other attacking
  states and 1 outside them (`((state != +734h) - 1) & 2`).
- **Stripped and debug code.** The task `+4h` DebugDraw overrides, `BSP_BotStateKamikazeAim_DebugDraw`
  (`009ACD90`, gated by `BSP_DebugFeatureOwner_GetSingleton()+2Ch`), `BSP_BotStateMoveToCircle_DebugDraw`
  (`009C2670`) and the ship-AI debug draws (`009DDCC0` and its helpers) only draw.
- **Unreferenced code.** 74 functions have no rel32 or absolute reference: several
  `FollowStateForRole` pickers whose owning class is not established (they are named with their
  address), task `Create` helpers (`009BACB0`, `009BAD30`, `009BBEF0`, `009BBF60`), the tightturn
  builders `009BB4A0`/`009BB530`, `009BBE20`, plain dword-array helpers and entity casts.
- **RNG.** Stream-1 draws appear in `009A1F00`/`009A1FC0` (stay-close delay), `009A75C0`, `009A79F0`,
  `009A8020` (dogfight state timers), `009BBAD0` (split-S side), `009D02A0` (torpedo aim error),
  `009CA730`, `009D5D60` and `009B94B0`. Recorded in the evidence only.

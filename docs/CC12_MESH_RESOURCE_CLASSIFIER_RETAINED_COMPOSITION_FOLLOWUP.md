## Semantics a later attachment must preserve

Root traversal captures actual current virtual entries and reloads the current manager resource before appending. Unknown resource tags may produce a null fallback allocation; base append still receives that null. `71BB40` appends to the primary array first and only then returns for null. For nonnull items it tests aux64 before convex54 before geom44, reacquires the item table at the observed points, and appends to only the first matching derived list. These arrays borrow pointers; classification performs no item retain and adds no rollback.

Root end-renderer dispatch happens only after normal traversal. Its exception cleanup releases only active child state and a still-constructing fallback allocation; it does not undo completed items. Mesh acquired subsets, buffers, metadata, textures and generators retain their partial progress/failure state. No cleanup retry or new replay policy is admitted by this audit.

`B80720` publishes the requested factory before the cache lookup. A hit retains and returns the current resource without clearing the factory. On a miss it uses current stats/factory/VFS entries, ignores the observed resolution and cache-insert results, clears the factory at the observed point, reloads stats and writes the wrapping metric difference to the current resource. Acquired load and nested VFS resolution frames must remain retained after failure. Invented null checks, copied publications and automatic rollback would change behavior.

Game-container destruction frees its borrowed derived arrays and then delegates to base destruction. Base destruction decrements each current primary item, without adding a null guard, and dispatches current zero-reference deletion when required. It then removes the resource from the actual manager, destroys hierarchy records through the same pool and releases actual string storage. Animation group/channel scalar deletion uses the captured owner/table and flags1 rather than an invented group reference decrement. Failure preserves partial progress; completed destruction cannot be retried as if nothing happened.

# Raw VFS provider enumeration dispatch, BG

`00BE1130` captures the current numeric provider table `+14h` entry and passes it with the actual provider, original suffix/extension string headers, flag DWORD and `0Ch` pooled string vector to `NativeVfsProviderEnumerationDispatch`. This source binding preserves those values and routes four verified numeric entries: physical `00BF47E0`, FileStore `00BE6480`, MPKG `00BB98F0`, and MPAK `00BB5F40`. It borrows retained provider-specific contexts and uses their concrete raw-storage implementations. An unknown entry throws a source error; it cannot silently produce an empty scan. No native function address is claimed by this composition module.

The binding owns no VFS manager, provider, string pool, archive or publication. The owner must retain `NativePhysicalEnumerationContext`, FileStore's actual string storage and invalid-parameter callbacks, `NativeMpkgDirectoryContext` and original `00E17BF0` null-pattern bytes, and `NativeMpakRuntime` until enumeration completes. It also must supply the outer enumeration visitor's duplicate logger and actual numeric visitor table. Provider operation failure is not translated into a fabricated result.

This module is a source routing prerequisite for the existing `00BDD990` visitor. It does not wire `GameNativeVfsRuntime` or `0073CB10` package scanning, and it makes no authentic archive or game-runtime claim. The physical and FileStore modules are separate BF dependencies. Win32 translation-unit compilation and source review cover the route, with full integration/build owned by the primary after shared CMake registration.

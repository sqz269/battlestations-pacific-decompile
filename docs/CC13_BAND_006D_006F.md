## Reconstruction: src/marker_manager_cc13.cpp (reconstructed, build-tested)

`include/bsp/marker_manager_cc13.hpp` holds the instance layout, `MarkerInstanceState` (20h), and
two host interfaces. The scene-instance calls, root registration, the RNG on stream 1, the clock and
the owner pose go through `MarkerInstanceHost`. The highlight side effects go through
`MarkerHighlightHost`. The highlight edits work on `MarkerManagerState` from world_entities.hpp.
They insert sorted by pointer so the vectors keep the native set order.

| native | C++ | ABI |
|---|---|---|

| 006D74D0 | destruct_marker_instance_006d74d0 | ECX this, RET |

| 0042B4D0 | rotation_z_0042b4d0 (file-local) | ECX dst, (float) RET 4 |
| 006D6170 | marker_vec3_less_006d6170 | (a*, b*) RET 8, AL |
| 006DAE20 | add_gui_highlight_006dae20 | ECX manager, (element, recursive, tinted) RET 0Ch |
| 006DC5A0 | remove_gui_highlight_006dc5a0 | ECX manager, (element) RET 4 |

Evidence and uncertainty:
- **Constants.** Phase range 4242.0f (00CF8F74). Mode 4 bob amplitude is the qword 25.0
  (00CE3880, FMUL qword at 006D817B). Highlight reset 0.28*0.0 (00CF8FC8 qword). Angles are
  `-0.0f - phase` (00D7A208, SUBSS).
- **Phase.** `FLD t; FADD ST0,ST0; FADD float phase; FSTP float`. The C++ sums in double, and the
  native sums in x87 extended before rounding to float. Mode 4's FSIN runs in extended precision;
  the C++ uses double `sin`. Both can differ in the last float bit.
- **Pose matrix.** Modes 1-3 copy the rotation over the whole identity, then the translation row
  (12..14) is written. Mode 4 leaves the identity and lifts y.
- **Unwired.** `host.marker_update` in the world tick and `marker_set_scale_006dbac0` in
  `game_hosts_mission_frame.cpp` (cc9's file) are still empty. Wiring is a host decision, and it
  must keep the stream-1 RNG separate from gameplay stream 0.
- **Not reconstructed.** `006DDA40` (ForgetEntity) needs entity-id keys that `MarkerGroup` does
  not carry. `006DBAC0` has a register ABI that is not settled.

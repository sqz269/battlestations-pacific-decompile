## What the band holds

### Lua mission event subscriptions (88 names)

`BSP_WarningManager_ParseEventBlock` 0097E360 turns a mission event block into a subscription object.
The block's type string is compared, in this order, with "recon" (`__stricmp`, skipped when the
string is null), then with `BSP_NativeString_EqualsCStringInsensitive` 00425850: "kill", "hit",
"exitzone", "input", "surrender", "failure", "leak", "fire", "repair", "zone", "command", "target",
"ammoType", "stock", "gui", "generate", "player", "musicOver", "chat", "entityKilled", "shipLanded",

[3] Matches. An unknown type, or a null type string, leaves the object pointer 0 and the native

## Verification notes

- The event order and allocation sizes come from the listing of 0097E360 (each `PUSH size` before
  `CALL operator_new` 00BF681B, then the constructor call); the decompiler's nesting lists the
  constructors in reverse, which is why the table was read from the assembly.
- Every vtable claim was read from the image bytes (`local/gp_vtrow.py`, `local/ng2_vtdump.py`), and
  every constructor/vtable pair from a Ghidra xref to the vtable address.
- `tools/verify_report_calls.py` checks JSON reports; this packet has none. No `bsp_game` run.

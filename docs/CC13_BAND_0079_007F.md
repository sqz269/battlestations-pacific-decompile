# Band 00790000-007FFFFF: template and engine pass (cc13-sweep79)

Packet cc13-sweep79, 2026-10-12, branch `agent/cc13-sweep79` (base origin/main `760c88179`). This is
the last band no cc13 band sweep had covered. Most of it is gameplay and belongs to cc9 (planes,
squadrons, bots, rocket tasks), so this pass:

1. ran the template pipeline and reviewed every `stl_probable` row in the band;
2. named the non-gameplay islands: the movie camera in segment 45, MovCam helpers in segment 46,
   and the player profile, session and race-record code in 007F7000-007FFFFF;
3. reconstructed a few anchored leaves;
4. lists the gameplay code left for cc9.

- `src/band_0079_cc13.cpp` is reconstructed and build-tested. It is not wired into a host and

## 2. Template copies

### 2.1 The st1 pipeline

The pipeline ran over segments 45-49 with `--range 00790000 00800000`:

```
python tools/template_shapes/st1_shapes.py 45 46 47 48 49
python tools/template_shapes/st1_auto.py; st1_rules.py; st1_family.py
python tools/template_shapes/st1_build.py --range 00790000 00800000
```

It produced 92 rows. 75 were written to `config/tags` with source `docs/CC13_BAND_0079_007F.md`
and applied with `st1_apply.py` under the lock: 75 renamed, 0 errors. By category:

- 51 `stl_shape`: 27 twins, 8 `dealloc`, 7 `alloc`, 6 `treedtor`, 2 `treeminmax`, 2 `rotate`;
- 17 `cg_adjustor_thunk`;
- 6 `cg_scalar_deleting_dtor`;

Every twin group was checked against its reference body (`local/sw79_twins.py`). For example,
`00793500` is the float twin of `STL_Pod8Range_UninitializedCopy_00419930`, and `007B3360` is
`sub ecx,310h; jmp` like `CG_adjustor_thunk_004e6660`.

The 17 `st1_scl97` hits were **not** written as bookmarks. Review section 3.1 item 4 says a hit on
"calls `_invalid_parameter_noinfo`" alone stays out of the tag set. They were decided with the
older rows below.

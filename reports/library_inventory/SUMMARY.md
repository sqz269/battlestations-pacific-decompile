## 5. Import / match plan

- **Lua 5.1.1**: exactly 5.1.1 (findfile calls luaO_pushfstring, changed in 5.1.2). Compiled in-tree with MSVC 2005 LTCG, so byte identity is impossible; match at source level with the 324-entry address map in `lua.json` (282 high confidence). Three deliberate edits to carry: l_alloc (00a6a1d0) routes to GameAlloc 00bd1780 / GameFree 00bd17a0; base_funcs (00d57c78) drops dofile; mathlib (00d57240) drops random/randomseed. linit.c is not linked: the script-state constructor 00b6a020 walks lualibs 00d62bb8 with a bitmask (second table 00cf8350 omits package). Source already at build/win32/_deps/lua511-src.
- **zlib 1.2.1**: stock, deflate + inflate, gzip wrapper on, BYFOUR crc32, stock zcalloc/zcfree over CRT malloc. 50 defined + 2 undefined (deflate_fast 00bcbf40, inflateSetDictionary family 00bcacf0) all mapped in `zlib_and_borrowed.json`. Vendor checksum-pinned source under third_party; validate with a compress/uncompress round-trip. The 8 game wrappers (00bbbe10/00bbbf00/00bbc1d0/00bbc320, 00b6c0e0/00bd3ec0, 00b6d1b0/00bd48f0) stay game code.
- **CRT/STL**: VS2005 FID (vsOlder_x86) is already applied (712 hits, 707 in the cluster); the 322 unmatched FUN_ inside the cluster sampled as CRT helpers. Exclude by range and link the modern CRT/STL in the rebuild. No VS2005 toolchain is installed (only MSVC 14.29/14.44/14.51).
- **Telemetry + pipe helper**: stub behind the 5 wrapper entry points; identify the pipe helper's vendor before stubbing.
